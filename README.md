## 🎮 MNEL Project Unleashed

### 🇬🇧 English

Welcome to MNEL Project Unleashed – an unofficial, fan-made port of Sonic Unleashed (Xbox 360) for Jailbroken PlayStation 4.

#### 📌 About the Project

This project is a full recompilation of the original Xbox 360 version of Sonic Unleashed, designed exclusively for jailbroken (hacked) PS4 consoles. It is not compatible with official or retail PS4 systems, as it is an unofficial port created for the homebrew community.

This port is based on the original Unleashed Recompiled project by hedge-dev on GitHub, but has been rebranded as MNEL Project Unleashed by Mani Mokhtarzadeh, who is leading this specific PS4 adaptation.

#### 🧪 Development Status

⚠️ This project is currently under active development, and a PKG file will not be released anytime soon. Please be patient and check back for future updates.

#### 🚧 Technical Challenges & Current Status

⚠️ **We have recently discovered that the PS4 does not recognize DDS image files.** As a result, we have temporarily **commented out** the DDS image includes in the source code to allow compilation to proceed.

However, if we continue this way, the final installer may **launch without any images at all** — including the **button icons** required for navigation, and even the **game settings menus** that were full of DDS images. This means the installer could be completely **visually blank** in those sections.

📌 **Important Note:** Once the PKG file is built and uploaded to GitHub, the **full installation instructions will be provided** — even without the button icons being visible — so you can still install and play the game. But to **generate the required GNF files** for PS4, we unfortunately need **professional tools** and I **cannot do this alone**.

🤝 **If you are willing to help**, please contact me via **GitHub Issues**, **email**, or any other method you prefer. I will then upload the required files that need to be converted, so you can assist in the conversion process.

Thank you,
Mani Mokhtarzadeh (ManiNetEasyLight)

#### 🛡️ Copyright & Usage

🛑 Due to the high risk of unauthorized copying and misuse of this project's source code, **the source code will not be released** for several months (or an indefinite period) after the PKG file is uploaded to GitHub. Please respect this decision.

📌 Furthermore, even if the source code is eventually released, **unauthorized copying or using it for re-uploading is strictly prohibited without written permission from the author**. Respected developers may only use the code to manually build a PKG file for personal use.

Thank you,
Mani Mokhtarzadeh (ManiNetEasyLight)

### 🇯🇵 日本語

MNEL Project Unleashed へようこそ – Xbox 360版『Sonic Unleashed』 を Jailbreak（改造）されたPlayStation 4 向けに移植する非公式のファンメイドプロジェクトです。

#### 📌 プロジェクトについて

このプロジェクトは、オリジナルのXbox 360版『Sonic Unleashed』を完全にリコンパイルし、改造されたPS4専用に設計されています。公式のPS4とは互換性がなく、ホームブリューコミュニティのために作られた非公式な移植版です。

このポートは、GitHub上の hedge-dev によるオリジナルの Unleashed Recompiled プロジェクトを基にしていますが、このPS4向け移植を主導している マニ・モフタルザーデ によって MNEL Project Unleashed に改名されました。

#### 🧪 開発状況

⚠️ このプロジェクトは現在積極的に開発中であり、PKGファイルはすぐには公開されません。今後のアップデートをお待ちください。

#### 🚧 技術的な課題と現状

⚠️ **PS4がDDS画像ファイルを認識しないことが最近判明しました。** そのため、コンパイルを進めるために、ソースコード内のDDS画像のインクルードを一時的に**コメントアウト**しています。

しかし、このまま進めると、最終的なインストーラーは**画像が全く表示されない状態で起動する可能性があります** — ナビゲーションに必要な**ボタンアイコン**や、DDS画像でいっぱいだった**ゲーム設定メニュー**も含めてです。つまり、インストーラーはそれらのセクションで**完全に視覚的に空白**になる可能性があります。

📌 **重要なお知らせ:** PKGファイルがビルドされGitHubにアップロードされたら、**完全なインストール手順が提供されます** — ボタンアイコンが表示されなくても — ゲームをインストールしてプレイできます。しかし、PS4に必要な**GNFファイルを生成する**には、残念ながら**専門的なツール**が必要であり、私**一人ではこれを進められません**。

🤝 **協力していただける場合**は、**GitHub Issues**、**メール**、またはその他の方法でご連絡ください。変換が必要なファイルをアップロードしますので、変換作業をお手伝いください。
