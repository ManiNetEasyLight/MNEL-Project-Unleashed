## 🎮 MNEL Project Unleashed

### 🇬🇧 English

Welcome to MNEL Project Unleashed – an unofficial, fan-made port of Sonic Unleashed (Xbox 360) for Jailbroken PlayStation 4.

#### 📌 About the Project

This project is a full recompilation of the original Xbox 360 version of Sonic Unleashed, designed exclusively for jailbroken (hacked) PS4 consoles. It is not compatible with official or retail PS4 systems, as it is an unofficial port created for the homebrew community.

This port is based on the original Unleashed Recompiled project by hedge-dev on GitHub, but has been rebranded as MNEL Project Unleashed by Mani Mokhtarzadeh, who is leading this specific PS4 adaptation.

#### 🧪 Development Status

⚠️ This project is currently under active development, and a PKG file will not be released anytime soon. Please be patient and check back for future updates.

#### 🚧 Technical Challenges & Current Status

Unfortunately, due to the **incomplete nature of the OpenOrbis PS4 SDK**, the project may **be delayed for several weeks or an indefinite period**. Instead of focusing on building the final PKG, I am currently **researching solutions to resolve the compilation errors** that have blocked further progress.

At this moment, **there is no complete or professional SDK available** for porting this game to PS4. However, **if such an SDK exists, please share the website link or download link** — or send it via email to **mani.sonia.rose.blue@gmail.com** — so I can download and use it!

Since I haven't been able to find a suitable SDK, I am currently **exploring alternative solutions** such as using **Docker Desktop, Docker images, and WSL** to find a working build environment. 

Under any circumstances, **please be patient**, as the project has temporarily hit a bottleneck and I need to find a new path forward.

Thank you,
Mani Mokhtarzadeh (ManiNetEasyLight)

#### 🛡️ Copyright & Usage

🛑 Due to the high risk of unauthorized copying and misuse of this project's source code, **the source code will not be released** for several months (or an indefinite period) after the PKG file is uploaded to GitHub. Please respect this decision.

📌 Furthermore, even if the source code is eventually released, **unauthorized copying or using it for re-uploading is strictly prohibited without written permission from the author**. Respected developers may only use the code to manually build a PKG file for personal use.

#### 📌 プロジェクトについて

このプロジェクトは、オリジナルのXbox 360版『Sonic Unleashed』を完全にリコンパイルし、改造されたPS4専用に設計されています。公式のPS4とは互換性がなく、ホームブリューコミュニティのために作られた非公式な移植版です。

#### 🧪 開発状況

⚠️ このプロジェクトは現在積極的に開発中であり、PKGファイルはすぐには公開されません。今後のアップデートをお待ちください。

#### 🚧 技術的な課題と現状

残念ながら、**OpenOrbis PS4 SDK が不完全である**ため、プロジェクトは**数週間または無期限に延期される可能性があります**。最終的なPKGのビルドに焦点を当てる代わりに、現在は**コンパイルエラーを解決するための方法を調査**しています。

現時点では、**このゲームをPS4に移植するための完全でプロフェッショナルなSDKは存在しません**。しかし、**もしそのようなSDKが存在する場合は、ウェブサイトのリンクまたはダウンロードリンクを共有してください** — または **mani.sonia.rose.blue@gmail.com** までメールで送信してください — ダウンロードして使用できるようにします！
