# MNEL-Project-Unleashed
MNEL Project Unleashed is a fan-made port of Sonic Unleashed (Xbox 360) for Jailbroken PS4. Fully recompiled, unofficial, and not for retail consoles. Based on hedge-dev's original recomp. Developed by Mani Mokhtarzadeh. Work in progress – no source or PKG files yet. Future PS5 support possible. Unauthorized copying is prohibited.
